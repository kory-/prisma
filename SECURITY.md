# Security

For a security concern, use [GitHub private vulnerability reporting](https://github.com/kory-/prisma/security/advisories/new). Avoid posting exploit details or private data in public issues.

Prisma is an early public preview. Only the current preview is maintained; no response-time guarantee is offered.

Audio, Chrome and Stream Deck integrations run locally. Review [Privacy](PRIVACY.md) for exchanged metadata and the limitations of local IPC. Prisma does not defend against another process with the same macOS user privileges.
